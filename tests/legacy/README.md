# Legacy tests (pre-redesign)

These are the original ad-hoc scripts written for the legacy engine, before the M1-M12
redesign. They are kept for reference only and are NOT part of the active suite. The redesign
is covered by the pytest-style suites in `tests/test_*.py` (13 suites, 80+ cases).

They will be retired when the live pipeline is cut over to `har2jmx.engine.analyze`.
